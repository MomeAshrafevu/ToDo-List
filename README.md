# 📝 To-Do List Web Application

A clean, responsive, and user-friendly To-Do List web application built with HTML, CSS, and JavaScript to manage daily tasks efficiently.

## ✨ Features

- **Add Tasks:** Quickly add new tasks to your daily list.
- **Mark as Completed:** Check off tasks once they are done.
- **Delete Tasks:** Remove unwanted or completed tasks easily.
- **Responsive Design:** Works smoothly across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Interactive functionality and DOM manipulation

1. Clone the repository:
   ```bash

   ```
2. Navigate to the project directory:
   ```bash
   cd ToDo-List
   ```
3. Open `index.html` in your preferred web browser.
